# 校园失物招领系统 目录说明与使用说明

## 一、项目技术栈
1. 后端：Python 3.x + Flask 轻量 Web 框架
2. 数据库：SQLite（文件型数据库，无需额外安装，首次运行自动生成）
3. 前端：HTML + CSS + 原生 JavaScript
4. 交互设计：移动端优先布局，适配手机端与电脑端浏览器

## 二、目录结构说明
```
campus_lost_found/
├── app.py                  # 后端核心程序：包含路由逻辑、数据库操作、所有业务处理
├── lost_found.db           # 数据库文件：首次运行后自动生成，存储物品、用户、通知等所有数据
├── static/                 # 静态资源目录：存放不随业务变化的资源文件
│   └── css/
│       └── style.css       # 全局样式文件：定义所有页面的布局、配色、组件样式
└── templates/              # 页面模板目录：存放所有 HTML 页面
    ├── base.html           # 公共基础模板：所有页面继承该文件，统一顶部、底部导航
    ├── index.html          # 1. 首页：分类入口、寻物 / 招领切换、最新发布列表
    ├── search.html         # 2. 搜索页：关键词搜索、热门标签、搜索历史管理
    ├── category.html       # 3. 分类浏览页：按物品种类定向筛选内容
    ├── detail.html         # 4. 物品详情页：完整物品信息、脱敏联系方式
    ├── contact.html        # 5. 联系发布者页：完整联系方式、认领防骗提示
    ├── notifications.html  # 6. 消息通知页：认领提醒、浏览提醒、状态更新、发布成功
    ├── all_items.html      # 7. 全部信息页：寻物 / 招领 / 全部 三类筛选的完整列表
    ├── publish.html        # 8. 发布信息页：类型切换、表单填写与提交
    ├── publish_success.html # 发布成功页：结果提示与跳转入口
    ├── my_posts.html       # 9. 我的发布页：个人发布统计、状态筛选
    ├── edit_status.html    # 10. 修改状态页：三种物品状态切换
    └── edit_success.html   # 修改成功页：状态更新结果提示
```
### 三. 核心功能操作指引

| 功能模块 | 操作说明 |
|---------|---------|
| 浏览失物招领 | 首页查看最新发布，点击「查看全部」进入完整列表；可切换「寻物 / 招领」筛选；点击顶部分类图标按品类浏览 |
| 搜索物品 | 点击首页搜索框进入搜索页，输入关键词可匹配物品名称、地点、描述；支持热门搜索快捷点击与历史记录 |
| 查看物品详情 | 点击任意物品卡片进入详情页，可查看完整物品信息、发布者、脱敏联系方式 |
| 联系发布者 | 详情页点击「联系认领」，可查看完整联系方式，支持一键拨打、复制微信号 |
| 发布信息 | 点击底部「发布」导航，选择「寻物 / 招领」类型，填写物品信息与联系方式，提交即可发布 |
| 管理发布内容 | 点击底部「我的」，查看自己所有发布内容；点击「修改状态」可标记为「已归还 / 进行中 / 暂停展示」 |
| 查看消息 | 点击底部「消息」，查看认领提醒、浏览提醒、状态更新、发布成功四类系统通知 |
### 四. 使用说明
#### 环境准备
- 操作系统：Windows / macOS / Linux 均可
- 软件要求：Python 3.7 及以上版本
- 第三方依赖：Flask Web 框架

#### 运行步骤
1. 将项目文件夹下载或克隆到本地任意位置
2. 打开命令行终端，进入项目根目录（包含 `app.py` 的目录）
3. 执行以下命令安装 Flask 依赖：
   ```bash
   pip install flask
4.执行启动命令运行项目：
```python app.py
5.当命令行输出 Running on http://127.0.0.1:5000 时，打开浏览器访问以下任意地址即可使用系统：
```http://localhost:5000
   http://127.0.0.1:5000



### 五. 注意事项
1. 运行期间请勿关闭命令行窗口，关闭后网站将停止服务；停止程序按 `Ctrl + C` 即可
2. 若需重置所有数据，删除项目里的 `lost_found.db` 文件，重新运行程序会自动生成全新空白数据库
